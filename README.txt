MACHINE FAILURE PREDICTION

Project Description:
This project predicts whether a machine failure may occur based on machine operating conditions.

Input Features:
1. Air Temperature
2. Process Temperature
3. Rotational Speed
4. Torque
5. Tool Wear

Machine Learning Model:
XGBoost

Application:
Streamlit

Project Components:
- Machine_Failure_Analysis.ipynb
- xgb_machine_failure_model.pkl
- streamlit_app.py
- requirements.txt

Output:
The application predicts:
1. Machine Failure Detected
2. No Machine Failure

The Streamlit application also provides an AI-based explanation and recommendation based on the prediction.
